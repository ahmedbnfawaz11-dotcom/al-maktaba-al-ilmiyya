# المكتبة العلمية للإمام محمد بن عبد الوهاب

مشروع تطبيق ويب تقدمي مستقل لعرض مؤلفات الإمام محمد بن عبد الوهاب رحمه الله، مع فصل المتون عن الشروح وتوثيق المصادر.

## الحالة
- تأسيس هيكل التطبيق.
- المحتوى العلمي يضاف بعد التحقق من النصوص والمصادر وحقوق النشر.
- لا تُعرض النصوص أو الشروح غير الموثقة على أنها محققة.

## التشغيل
افتح `index.html` في المتصفح، أو انشر المستودع عبر GitHub Pages.
